# 公開後運用プレイブック

Manifesto公開（2026-05-13）後の運用タスク。

## 公開後 1週間（〜5/20）

- [ ] 毎日1回、Issue / Discussion / メンションを確認
- [ ] 反応には24時間以内に応答（編集的トーンを維持）
- [ ] Star数の推移を [metrics.md](../metrics.md) に記録（隔日）
- [ ] 各SNSの反応（いいね・RP・コメント）を観察、過剰反応しない

## 公開後 2週間（〜5/27）

- [ ] 最初のフィードバックを受けて Manifesto を微修正（必要時）
- [ ] よくある質問が出たら Discussions に FAQ スレッドを立てる
- [ ] [metrics.md](../metrics.md) を週次更新

## 公開後 4週間（〜6/10）

- [ ] 公開1ヶ月の振り返りを appendix に追記

## 応答テンプレート（編集的トーン）

- 機能要望: 「提案ありがとうございます。SEO編 v0.1 のスコープ（4機能）との関係で、v0.2以降の検討対象として記録します」
- 質問: 「Manifesto の該当章（リンク）を参照してください。不足があれば追記します」
- 批判: まず論点を正確に言い換え、同意できる部分を認めてから、境界線を説明する

## やらないこと

- バズ狙いの過剰な発信
- 週20時間制約を超える運用
- 攻撃的な議論への参加
