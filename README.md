# The Marketing-OS Open Source Manifesto

🚧 **このリポジトリは現在構築中です** / **Under construction**

Marketing-OS は、マーケティングの意思決定構造を業界に開くプロジェクトを進めている。
このリポジトリはその思想ハブとして機能する。

Marketing-OS is opening its decision-making structure to the industry.
This repository serves as the conceptual hub of that effort.
